# Karyll

Karyll is a minimalistic writing app with bluetooth keyboard for jailbroken Kindle Scribe.

Tested on Kindle Scribe (2022; firmware 5.19.4.0.1).

## Build

```sh
git clone https://github.com/huangziwei/karyll && cd karyll/
./build.sh
```
